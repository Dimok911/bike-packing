## Application changes

- Temporary nested pouches are independent across layouts, including repair of
  previously shared records. Reusable catalog bags and items remain shared.
- Private pouch copying can add only items absent from the destination layout.
  Explicitly duplicated items receive a `copy` suffix.
- In v1645, each Items/Bags participation selector has its own `Дубликаты`
  option. The separate menu entry from v1644 was removed at the user's request.
  Matching names are candidates for manual inspection, never automatic deletion.
- Local undo retains up to 20 actions across reloads, works offline, and refuses
  conflicting newer state. Required photo references are retained for undo.
- Packing gestures refresh the active vertical scroll host after hidden-board
  renders and tab switches. Physical iPhone acceptance remains to be confirmed.
