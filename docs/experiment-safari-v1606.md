## Проверка опубликованной основы

Публичный контракт подтвердил v1604 и API `2026-08-30.catalog-review-v1`.
Сборка указанного commit совпала с публичными app.js, styles.css, sw.js,
release-contract.json и manifest.webmanifest по SHA-256 после сохранения
SVG-исходников с LF. HTML отличается только CR-переводами строк, его содержимое
совпадает полностью. Первый Windows build имел другой хэш динамического модуля
из-за CRLF внутри встроенного SVG; других различий app.js не было. В атрибутах
репозитория закреплены LF для HTML/SVG, чтобы локальный build соответствовал Linux.

## Неподвижные фотографии

Публикация разрешена только через `deploy-experiment-vps.ps1 -ApplicationOnly`.
Каждый требуемый asset должен уже существовать с точным хэшем. Архив содержит
только приложение. Общий каталог assets и его файлы не копируются, не меняют
расположение и не удаляются. Новому каталогу приложения создаётся ссылка на
существующий assets. Откат также меняет только приложение.

Пять интеграционных проверок нового remote entry point обязательны в Linux CI:
активация/откат, потеря ответа, конкурентное изменение live, неверный asset/путь
и отказ проверки после rename. Проверяются содержимое, inode, ctime и число
ссылок фото и их каталога. Локальные Windows skips не считаются прохождением.

До успешного `Frontend quality` для точного SHA, сверки живого API, staging и
публичных хэшей выпуск не завершён. Production, Shared Auth, proxy и API не менять.
