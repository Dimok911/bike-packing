# Продолжение и остановка административной отправки

Локальный этап 10.09.2026, без публикации. Рабочие флаги выключены;
backend остаётся `068c1eb`. Отложенные шесть файлов галереи не изменяются.

Кнопка синхронизации в административном редакторе с ожидающими действиями
открывает их состояние. Доступны проверка результата, продолжение прежней
отправки и подтверждаемая остановка. Проверка читает квитанции; продолжение
использует исходные ID. Отказ в окне подтверждения остановки ничего не меняет.

Остановка сохраняется отдельным решением для всей выбранной цепочки **до**
первого запроса отмены. Решение содержит исходные планы с проверенными хешами
и местный снимок редактора. Сначала отменяются зависимые действия, затем их
предшественники. Независимые планы и внешние производители зависимостей не
отменяются. Уже подтверждённые изменения остаются принятыми сервером.

Обычный flush после reload выполняет сохранённую остановку. Решение учитывается
и между операциями одного плана, если оно пришло во время предыдущего запроса:
подтверждённое сохранение не запускает ещё не начатую публикацию. Сбой между
общим решением и записью флага отдельного плана не возобновляет обычную отправку.
Новая правка не дописывается к остановленной зависимости без явной сверки.

Аккаунт, права, маршрут и местный редактор проверяются между ожиданиями.
Нехватка места и повреждение решения останавливают действие, сохраняя местный
вариант. Ответ на старую операцию не очищает текущий черновик.

## Явное сохранение местного варианта после остановки

Окно предлагает сверку только после проверенного завершения всей остановленной
цепочки. Читает актуальный серверный вариант и показывает содержимое обеих
сторон: вещи, сумки, количество, вес, вложенность и описания. Отказ не создаёт
действия. Подтверждение сохраняет обе версии и исходную остановленную цепочку
до создания отдельного нового плана. Этот план использует просмотренную версию
сервера и сохраняет её видимость; опубликованный шаблон отмечен предупреждением.

Решение отдельно привязано к старой цепочке, аккаунту и редактору. При reload
оно восстанавливает ровно один новый UUID и исходную версию, даже если сбой
произошёл до записи плана или ссылки редактора. Старая неудачная правка в памяти
не блокирует одобренное продолжение. Повторное изменение сервера приводит к
конфликту. Изменение местного снимка, аккаунта, прав или маршрута останавливает
сверку. Удалённый/отсутствующий серверный шаблон не создаётся заново.
