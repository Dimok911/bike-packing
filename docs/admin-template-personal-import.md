# Подтверждённый административный шаблон → личная укладка

Локальная работа 11.09.2026, без публикации. BE `3064165` сохранён только
локально. Исходные флаги выключены. Это ещё не завершение крупного раздела 11.

Подключены обычные формы копирования вещи, дерева сумок, пустой сумки и кармана
из редактора demo/shared в выбранное место личной укладки. Полная версия
административного источника читается перед подтверждением, сравнивается с
редактором и привязывается к действию через revision и SHA-256. Публикация
шаблона для этого не требуется; сервер проверяет текущие права администратора.

Дополнение 11.09: форма «Укладка из шаблона» создаёт отдельную личную укладку
через тот же сохранённый выбор. Доступен открытый административный черновик,
даже если независимый каталог его ещё не показывает. Копируются размещённые
записи и их количества; пустая исходная укладка даёт пустую личную укладку,
отдельные записи каталога источника автоматически в неё не добавляются.
Название и источник проверяются после подготовки. При переключении внутреннего
контекста форма сохраняет выбранный шаблон; ожидающая правка источника блокирует
создание. Создание цели для другой незавершённой копии остаётся отдельным этапом.

Копия использует существующий личный планировщик, новые ID и неизменяемый
сохранённый выбор. Каталожное количество остаётся 1; количество размещения
сохраняется из выбранного источника, в том числе для отдельной вещи. Исходные
вещи, сумки и размещения не меняются. Изменение источника, цели, аккаунта или
появление ожидающей правки останавливает ранее открытый выбор.

Отмена возвращает пользователя в исходный редактор. Открытие/восстановление
редактора шаблона и восстановление выбранной личной вкладки больше не создают
пустых действий сохранения личного списка. Копирование не обходит реально
ожидающие личные изменения.

После обрыва ответа и перезагрузки используется существующая кнопка
«Продолжить сохранённую форму». Она сверяет сохранённое действие с его
подтверждением. После завершения проверки повторная перезагрузка восстанавливает
личную копию; серверная команда не отправляется второй раз.

Дополнительные проверки покрывают три границы нехватки места. Если не записан
даже выбор источника, отправки нет: блокирующий экран позволяет скачать архив
с полным выбранным источником и выделенными ID. Он помечен как черновик для
восстановления, а не готовая команда. Если выбор уже сохранён, но не записано
действие или связь с очередью, явное продолжение после перезагрузки использует
те же ID и состав копии. При отказе до применения новой укладки прежняя выбранная
вкладка сохраняется; восстановленная укладка появляется в списке выбора.

«Только недостающие» добавляет новые вещи в существующие сумки, сохраняет
количества и прежние записи. Следующая обычная правка подтверждённой личной
копии использует новую серверную версию и отдельный UUID.

Сервер принимает отдельный источник `kind: admin-template` внутри
`publicImport`, с независимым флагом и capability
`personalCausalAdminTemplateImportV1`. Под одной транзакцией проверяются
административный head, точный namespace, исходная и целевая версии, весь
исходный снимок и права перед фиксацией. Общая блокировка каталога берётся
до личного журнала: одновременные копии в противоположных направлениях
завершаются одним принятым действием и конфликтом второго.
