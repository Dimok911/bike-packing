# Снятие размещения и удаление после ожидающей правки

11.09.2026. Проверка общего адаптера из `admin-template-pending-target.md`.
Публикации нет, исходные флаги OFF. Код приложения и API не менялся.

Через настоящие формы проверяются снятие вещи/корневой сумки с укладки и
удаление из каталога. Предыдущая правка данных или параметров сохраняется
отдельно; новый план ждёт её UUID и не перечитывает старый серверный вариант.
При снятии размещения вещи остаются в каталоге. При удалении сумки сохраняются
её вещи и многоразовые карманы; удалённая запись не возвращается при повторе.

UI-матрица: 44 новых сценария, demo/shared и Chromium/mobile WebKit.
Основные действия после правки данных; удаление корня после параметров,
потери ответа предшественника, отказа плана/зеркала, отмены и изменения цели
в открытом подтверждении; удаление вещи после потерянного ответа. Проверяются
точные записи и размещения, один дочерний запрос, прежний UUID, следующая
правка и повторное открытие. При отказе первого зеркала восстанавливается
полный снимок, при нехватке места для плана выбранное удаление ждёт продолжения.
