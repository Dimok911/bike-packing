# Составная фотоформа личной сумки

Локальный этап 2026-09-09, после FE f1e73b6 / API 92f6abe (составная вещь).
Публикация и включение флагов не выполняются. Список перехода остаётся открыт.

Форма сумки фиксирует поля, новые файлы либо удаление/порядок прежних фото,
полную выбранную укладку и место в ней одним `photos.mutate/action=form`.
Поддерживаются новая пустая корневая сумка, перенос существующего дерева,
подъём вложенной сумки в корень, перестановка корней и вставка в том же
родителе. Для добавления из другой укладки фиксируется её полный снимок.
Без выбранного источника добавляется только явно выбранная пустая сумка;
содержимое из другой укладки не перечитывается неявно.

`containerFormContext.version=1` содержит `targetLayout`, `sourceLayout`
(null либо полный выбранный источник), `targetParentId`, `targetIndex` и
`layoutFields`. Он несовместим с item `formContext` и `copySource`.
Обычная форма без контекста сохраняет прежний протокол. Файлы и их номера,
выбранные снимки и поля фиксируются до асинхронного чтения/записи.

Перенос дерева сохраняет его строки, порядок, количества и упаковку. При
новом размещении выбранного содержимого в другой укладке количества начинают
с 1 и упаковка не переносится, как в существующем пути добавления сумки.
Исходная укладка остаётся прежней. Циклы, пересечение выбранных ID с целью,
изменённый источник, public/shared владельцы и закрытая укладка отклоняются.
Перемещения между корнем и вложенным положением учитывают флаг `nestable`.
