## Relevant code and limits

loadHistoryRecordDetail and historyRecordState in app.js pass historical
snapshots through normalizeRemoteState, which performs live layout cleanup
and temporary-container isolation. Applying live migrations independently
while comparing snapshots can generate additional identity noise. Incomplete
container references are then presented as removed contents.

The temporary-container migration uses deterministic pouch IDs and remaps
placements; the observed replacements are consistent with this migration.
The step that failed to persist all corresponding catalog records has NOT
yet been established. Do not claim the incident is purely cosmetic or that
current server data is complete based on these history responses alone.

No history fix or data repair was published. v1647 contains only the requested
missing-only transfer dialog changes. Follow-up should reproduce the incomplete
snapshot through the migration/entity-sync path, verify current-state integrity
read-only, and separate history comparison from live data migrations. Preserve
real deletions and moves in regression checks; do not simply hide missing IDs
or suppress changes based on matching names.
