# Копирование дерева сумки в административном редакторе

11.09.2026. В том же подтверждённом demo/shared форма сумки теперь копирует
целое дерево, отдельный вложенный карман либо пустую оболочку. Выбранное
место и позиция фиксируются до подтверждения вместе с составом, новыми ID,
исходной revision и UUID. Копию кармана можно поставить перед оригиналом.

Чистый `prepareAdminTemplateTreeCopy` проверяет исходные ссылки, владельцев,
порядок, циклы, доступность вещей и отсутствие файлов. Он не восстанавливает
молча повреждённые связи. Копии получают независимые ID и теряют старую
публичную идентичность. Каталожное количество новой вещи — 1, размещённое
количество сохраняется из источника; отметка упаковки новой вещи пуста.
Прежние размещения, количества и отметки остаются прежними.

Один полный `template.save` защищает и источник, и место назначения исходной
revision. Зеркало сохраняется до журнала. Отказ зеркала откатывает добавление,
положение и целевого родителя; отказ журнала/ссылки редактора сохраняет план
для reload. Повтор читает ту же квитанцию. Изменение источника, цели, аккаунта
либо появление неподтверждённой правки отменяет прежний выбор до записи.

  подтверждение, потеря ответа, три квоты, reload, конфликт, смена источника,
  цели и аккаунта, pending-правка и отмена. Ещё 8 — регрессия размещения вещи.
- `resume-admin-tree-transport-1.txt`: **1181/1181**; чистый планировщик —
  5 тестов с несколькими отрицательными случаями внутри одного теста.
- `resume-admin-tree-critical-1.txt`: **899/899**; source check завершился
  с кодом 0 (`resume-admin-tree-check-1.txt`).
- `resume-admin-tree-api-2.txt`: **42/42** через изолированные MySQL/API.
  Шесть новых случаев используют настоящий клиентский планировщик и экспорт,

  Серверный тест сохранён локально в BE **e487221**, рабочий сервер не менялся.

Первый API-прогон выявил только расхождение ожиданий стандартных значений
пустого родителя и справочников. Сравнение уточнено; бизнес-данные сравниваются
целиком. Первый UI-прогон выявил недоступную позицию перед исходным карманом:
она открыта только для копирования в текущий административный шаблон.
