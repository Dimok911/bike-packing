# Вещь из неразмещённой сумки административного каталога

11.09.2026, продолжение после FE `ad0a81c` / BE `0ff6149`.
Без публикации, флаги OFF, серверный runtime `444808c` не менялся.
Парные серверные тесты сохранены только локально в BE `d166efc`.

Обычная кнопка добавления существующей вещи теперь принимает также вещь из
сумки/кармана каталога, которые ещё не включены в укладку. Выбранная вещь
переходит в целевую сумку с прежним ID и каталожным количеством; соседние
вещи остаются в исходной сумке со своими полями и порядком. Пустая исходная
сумка не удаляется. Каталожная запись и новое размещение сохраняются одним
планом от прежней версии шаблона.

Планировщик проверяет однозначную принадлежность источника и ровно одну
ссылку на него в прежнем родителе. Другой владелец, размещённый родитель,
повторная/отсутствующая ссылка или ссылка из другой сумки останавливают
действие без изменения состояния. Состав остальных записей не исправляется
неявно. Общий адаптер сохраняет изменённые существующие записи вместе с
целевым размещением; отказ первого зеркала восстанавливает и вещь, и прежнего
родителя. Более поздний отказ хранения/reload продолжают сохранённый UUID.
