# Личные действия: сохранение до изменения экрана

Пять адаптеров app.js теперь сначала сохраняют полный подготовленный снимок
через persistStateSnapshot, затем меняют state и обновляют представление без
повторного бизнес-действия. Это каталожные копии, дерево copy/link/missing,
удаление укладки, справочники и размещение/упаковка. UUID действия выбирается
до ожидания подтверждения и не меняется при выполнении.

При исчерпании localStorage прежнее состояние остаётся на экране. Реальный
personalSaveRecovery сохраняет полный выбранный черновик в recovery copy;
операция не выдаётся за подтверждённую. Повторное нажатие не создаёт второй
бизнес-пакет. Проверки действительных адаптеров используют настоящий outbox
и recovery, а не заменяют ошибку хранилища успешным ответом.
