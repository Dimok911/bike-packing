# Копирование в ещё создаваемую цель

11.09.2026, продолжение `admin-template-pending-target.md`. Без публикации,
исходные флаги OFF. BE `c04a6c1` только локально, обработчик `a631516` не менялся.

Новый административный шаблон или целая копия могут стать целью дерева до
подтверждения создания. Если в копии уже есть сумка, в неё можно скопировать
отдельную вещь. Дочерний план ждёт исходный ID создания; утрата ответа после
создания не порождает вторую цель. Отмена выбора и более поздняя правка цели
сохраняют прежний результат.

Проверка обнаружила реальную ошибку идентификаторов. Целая причинная копия
создаёт серверные ID `template-copy-…`, но обычный экспорт редактора добавлял
префиксы `item-`/`container-` и менял ID укладки на `layout-main`. Следующее
сохранение заменяло прежние записи вместо сохранения их идентичности.

Для причинной целой копии редактор теперь помнит исходный ID укладки и записей
в существующих полях источника. Экспорт сохраняет эти ID и все ссылки между
ними; новый редактор, открытый по подтверждённому серверному снимку, восстанавливает
ту же привязку. Недопустимый или повторный ID останавливает экспорт. Обычный
экспорт сохраняет прежние правила. Служебные поля источника не отправляются
в бизнес-снимке.

Сохранённые старые планы не переписываются. Если ожидающая целая копия хранит
прежние преобразованные ID редактора, новый выбор цели требует сначала
подтвердить её создание и явно сверить серверный вариант. Журнал и исходные
номера остаются для продолжения.
