## Когда отмечаем пункт выполненным

Одновременно выполнены: подключены реальные действия интерфейса, сохранены
данные и зависимости до отправки, есть соответствующий серверный обработчик,
пройдены проверки перезагрузки/повтора/потери ответа/перестановки запросов и
смены аккаунта. Для составных действий дополнительно проверены частичный пакет
и точная версия источника. Фиксируем изменённые файлы, пару frontend/backend
коммитов и результаты тестов. «Проверен отдельный модуль» не закрывает пункт UI.

Изменения темы, открытие модалок и другие действия без записи бизнес-данных
не превращаем автоматически в серверные операции. Каталог, Shared Auth, proxy
и deployment остаются вне этого списка реализации до отдельного разрешения.
