Кнопка «Заменить вещь» в demo/shared сохраняет замену одним планом от
подтверждённой версии. Выбранная вещь из каталога получает прежнее место,
позицию и количество размещения. Старая вещь остаётся в каталоге; её отметка
упаковки снимается. Если новая вещь находилась в неразмещённой сумке каталога,
из той сумки извлекается только она: соседние записи и их количества остаются.
ID записей не меняются. Фотографии пока блокируются общим ограничением адаптера.

Планировщик работает на копии состояния и проверяет точное преобразование
размещения, принадлежность записей, единственную ссылку на прежнюю вещь,
явное положительное целое количество и порядок. Неоднозначные данные не
исправляются автоматически. Общий адаптер сохраняет изменённые каталожные
записи вместе с размещением. Отказ первого зеркала полностью откатывает
изменения; последующие сбои продолжают сохранённый UUID.
