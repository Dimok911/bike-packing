## Этап A — закончить хранилище и восстановление (ближайший приоритет)

На этом этапе можно сохранить действующий сетевой API. Перенос в IndexedDB
и уменьшение сетевых запросов — разные изменения; не нужно ждать всей
частичной загрузки, чтобы исправить хранение на телефоне.

- [x] Реализовать атомарное хранилище IndexedDB и проверку ревизии.
- [x] Проверить точный перенос старых записей без удаления оригиналов.
- [x] Подготовить ожидание записи для подготовленных команд интерфейса.
- [ ] Подключить чтение текущих данных, исходной версии для сравнения,
      копий восстановления и очереди к одному хранилищу.
- [ ] Доделать отправку очереди, запись подтверждений и удаление только
      доказанно завершённых записей. Согласовать журналы транспорта и фото.
- [ ] Перевести обычные формы на подготовку отдельного результата,
      запись, затем применение; обработать создание первого списка.
- [ ] Сделать безопасное первое переключение, повторный запуск и обнаружение
      изменений из старой вкладки. Сохранить разделение аккаунтов,
      гостевых данных и черновиков администратора.
- [ ] Проверить полный путь на исходных данных пользователя:
      старая неподтверждённая запись → выбор серверной версии →
      перезапуск → выбранные серверные данные без повторения старой ошибки.
- [ ] После необходимых проверок выпустить только на экспериментальном
      стенде и проверить на реальном телефоне. Production отдельно.

Критерий завершения: приложение читает и сохраняет личные данные через
IndexedDB, переживает перезагрузку и сбои записи, а переход не теряет
исходную очередь. Одна новая библиотека хранения этому критерию не равна.

## Этап B — небольшие команды и независимые изменения

- [ ] Отправлять действие, его постоянный идентификатор, изменённые поля
      и необходимые версии вместо всех данных при каждом сохранении.
- [ ] Проверять состав и размещение отдельно по укладке, изменения самой
      вещи или сумки — по общей записи каталога.
- [ ] Разрешать независимые изменения разных укладок; действительные
      пересечения общей записи всё равно требуют проверки.
- [ ] Получать изменения с последней подтверждённой версии.
- [ ] Сначала сервер поддерживает старый и новый формат, затем постепенно
      переключается клиент. Повтор запроса не должен повторять действие.
- [ ] Полное сравнение снимков оставить для начальной загрузки и особого
      восстановления. Отсутствующую исходную версию нельзя выдумывать.

## Этап C — загрузка по мере необходимости

- [ ] Сначала лёгкий список укладок и выбранная укладка.
- [ ] Сервер возвращает её размещение и все связанные вещи и сумки,
      включая вложенные. Отдельные копии каталога на каждую укладку
      не создаются.
- [ ] Небольшие справочники загружаются целиком.
- [ ] «Вещи» и «Сумки» получают каталог порциями; поиск онлайн работает
      по всему каталогу на сервере.
- [ ] Полученные записи переиспользуются из местного хранилища.
      Файлы фотографий загружаются по необходимости.
- [ ] «Ещё не загружено» отличается от «удалено». Частичный набор
      нельзя отправлять старым способом как полную замену данных.
- [ ] Замерить холодный/повторный запуск и объём данных одного действия.

## Этап D — сохранить и расширить офлайн-возможности

Этот этап обязателен до включения частичной загрузки для пользователя.

- [ ] Сохранить существующий выбор укладок для офлайн-доступа.
- [ ] Добавить «Весь личный каталог офлайн»: все вещи, сумки, категории
      и места хранения. Без интернета доступны поиск и добавление
      этих записей в скачанную укладку.
- [ ] Сохранить отдельное управление фотографиями; выбор текстового
      каталога не скачивает автоматически все галереи.
- [ ] Сохранить отдельный офлайн-каталог моделей производителей.
- [ ] Показывать прогресс, незавершённые загрузки и проверенную готовность.
      Отметка выбора сама по себе не означает, что всё скачано.
- [ ] Продолжать прерванное скачивание; при неудачном обновлении
      сохранять предыдущую полную офлайн-копию.
- [ ] Не удалять неподтверждённые изменения, копии восстановления
      и записи, нужные другой выбранной офлайн-укладке.
- [ ] Проверить офлайн-поиск, добавление ранее не открытой вещи,
      справочники, перезапуск и переключение аккаунта.
