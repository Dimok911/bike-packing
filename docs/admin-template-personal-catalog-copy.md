# Вещь административного шаблона → личный каталог

Локальное продолжение перехода от 11.09.2026. Этот срез не публиковался;
исходный `PERSONAL_ADMIN_TEMPLATE_IMPORT_ENABLED` остаётся OFF.
Сервер `3064165` без изменений: его ранее проверенная матрица API/MySQL
237/237 уже включает отдельную каталожную копию.

В окне выбора места добавлена явная цель «В личный каталог вещей» с пояснением
«Без размещения в укладке». Она доступна при выборе незаблокированной личной
укладки для вещи из административного редактора. При выборе административной
цели и при выключенном флаге этой кнопки нет. Обычный выбор сумки сохраняет
прежний смысл.

Перед подтверждением фиксируются точный административный источник, версия,
снимок и новые ID. Используется существующий `list.import`, `publicImport`
с `source.kind: admin-template` и `copy.version: 3`, `copy.mode: catalog`.
Новых серверных команд или обходов очереди нет. Все личные укладки, размещения,
сумки и прежние вещи остаются неизменными. Размещённая вещь копируется как одна
каталожная единица; количество отдельной вещи вне укладки сохраняется из
подтверждённого каталога источника.

После надёжной локальной записи закрываются исходная карточка и выбор места,
открывается вкладка «Вещи». Отмена возвращает исходный редактор. Обрыв ответа
и нехватка места при связывании с очередью используют прежний сохранённый выбор,
его ID и явное продолжение после перезагрузки, без второй серверной команды.
Выбранные фотографии по-прежнему требуют отдельного адаптера и не отбрасываются.

  `resume-admin-reverse-catalog-ui-1.txt`. Demo/shared, вещь в сумке и отдельная
  каталожная вещь, подтверждение, обрыв, отмена, quota, неизменность всех
  прежних владельцев/размещений, количество 1 и 3.
- Critical **901/901**: `resume-admin-reverse-catalog-critical-1.txt`.
- Source check успешен: `resume-admin-reverse-catalog-source-1.txt`.
- Дополнительный UI **26/26**, оба браузера, без повторов/пропусков, 3,7 минуты:
  `resume-admin-reverse-catalog-regression-ui-1.txt`. Восемь новых проверок
  полностью пустого личного списка, две проверки выключенного флага и
  16 проверок прежних копий в сумки. Итого **40 новых сценариев каталога**
  и **18 проверок прежних форм/выключенного флага**.

фотографии и архивы, старые данные, хранение и аудит. Крупные критерии 2/12
и административные 0/10 не закрываются этим срезом. Нативные сбои WebKit
в прежних полных прогонах остаются отдельным открытым вопросом.
