# Остатки и подготовка укладки

`items[id].stockQuantity` — целый неотрицательный фактический остаток. Он
сохраняется в обычной записи вещи, локальных резервных копиях и существующем
entity sync API. Сервер уже сохраняет произвольные поля записи; смена API или
схемы БД не требуется. `arrangement.itemQuantities` остаётся планом отдельной
укладки и определяет её вес. Создание укладки и отметка «собрано» не списывают
запас.

При нормализации старых данных остаток без значения становится 1. Для личных
вещей с местом «Надо купить» / «Need to buy» он становится 0, а место — «Не знаю
где» / «Unknown location». Уже заданные остатки, включая 0, сохраняются.
Устаревшее место удаляется из личных справочников и вариантов выбора. Повторная
нормализация не сбрасывает покупки. Исходные публичные записи не мигрируют.

Справа под добавлением сумки три кнопки считают уникальные позиции текущей
укладки независимо от фильтров и свёрнутых сумок. «Докупить» сравнивает её план
с общим остатком. В пустой укладке без сумок кнопки скрыты; они появляются
после добавления первой сумки. При перетаскивании сумки место вставки находится
перед начальной плашкой или колонкой действий и сдвигает их вправо.
«Починить» учитывает «Нужна починка» и состояние «Сломано»;
«Зарядить» — «Требует заряда». Флажки в редакторе изменяют эти же категории.
«Нужна починка» и «Требует заряда» — встроенные категории: доступны во всех
списках выбора даже при пустом пользовательском справочнике, не удаляются и
не переименовываются. Они не занимают лимит пользовательских категорий и не
назначаются вещам или сумкам автоматически. При удалении другой категории
они не используются как категории замены. Существующие одноимённые категории
используются без создания второй записи. «Нужна починка» не меняет состояние
вещи и не запрещает использование; состояние «Сломано» по-прежнему запрещает
добавление вещи в укладку.
Каждая кнопка открывает перечень вещей с теми же миниатюрами, что и список
добавления в сумку. Нажатие на фотографию или название открывает карточку вещи.
Во вкладке «Вещи» карточки на компьютере резервируют три строки названия:
остатки выровнены, плашки подготовки расположены поверх фото. Подсказка
«Докупить» указывает текущую укладку, план, остаток и недостающее количество.
Частичная покупка прибавляет введённое
количество к запасу; количества остальных укладок не меняются.

В публичном просмотре личный запас и кнопки подготовки скрыты. Экспорт
публичной укладки и ссылки на отдельные вещи не передают `stockQuantity`.

Проверки: `npm run test:inventory`, `npm run test:critical`,
`npx playwright test tests/e2e/inventory-preparation.spec.js --project=chromium`.
