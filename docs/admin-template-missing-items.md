# Недостающие вещи в административном шаблоне

11.09.2026, продолжение FE `fc72cbc`. Без публикации, флаги OFF.
Backend runtime `444808c` не менялся; серверные коммиты только локальные.

При копировании сумки можно добавить только недостающие вещи в уже
существующие сумки цели. Состав, новые ID, найденные родители и количества
фиксируются до подтверждения. Между шаблонами один `template.save` содержит
исходные версии цели/источника и digest подтверждённого серверного источника.
Внутри одного шаблона используется та же исходная версия без внешнего источника.

Сопоставление использует прежние признаки сравнения каталожных записей.
Количество для сравнения размещённых вещей берётся из укладки; каталожное
количество новой размещённой копии равно 1, количество в укладке сохраняется.
Существующие вещи, их количество и порядок не меняются. Новые вещи добавляются
после текущего содержимого. Если исходный карман не сопоставлен, используется
сопоставленная корневая сумка, как в прежнем публичном режиме добавления
недостающего. Новые сумки этим действием не создаются.

Две подходящие целевые сумки считаются неоднозначностью: вариант добавления
недостающего недоступен. Весь исходный и целевой arrangement проверяется до
копирования; нормализация не должна молча чинить потерянные количества или
ссылки. Проверяются владелец и отсутствие файлов в читаемом составе.

Режимы полной независимой копии и добавления существующей сумки сохранены.
Если одновременно доступны добавление существующей и добавление недостающего,
сначала выбирается «Только недостающие» либо «Вся сумка»; второй вариант
открывает прежний выбор копии/существующей сумки. Отмена в любом окне сохраняет
исходные данные. Все варианты используют уже подготовленные снимки.
