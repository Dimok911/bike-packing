# Ожидающая копия шаблона как источник следующего действия

Продолжение 11.09.2026, без публикации перехода. Исходные флаги OFF.

После сохранения плана целая копия demo/shared может стать источником ещё
одной целой копии, вещи или дерева в другом подтверждённом шаблоне. Цепочка
«правка A → копия B → копия C» сохраняет UUID каждого шага до отправки.
Сервер ждёт именно B; содержимое A не подставляется вместо промежуточной копии.

У плана B два разных снимка. Снимок редактора проверяет неизменность выбора,
а серверный снимок повторно вычисляется из сохранённого исходника и UUID B.
Следующая копия хеширует серверный снимок с новыми идентификаторами B.
Нормализованный снимок редактора не используется как серверное доказательство.
План читается через существующую проверку целостности и полного формата;
несохранённая правка, отменённый или повреждённый план не допускаются.

После принятия B удаление A не мешает C. Изменение версии B до принятия C
даёт окончательный отказ без изменения цели. Принятый результат C остаётся
тем же после удаления B, повторной доставки и перезапуска сервера.
Потерянный ответ B не должен создавать второй экземпляр B.

Проверки используют отдельную тестовую MySQL и управляемый браузерный API:

- API/MySQL **313/313**, 273,5 секунды: `resume-copy-source-api-1.txt`.
  16 новых сценариев demo/shared, целая копия и сохранение существующей цели,
  обратный порядок доставки, перезапуск, отмена B, изменение B и удаление A.
- Целевые модульные **12/12**, очередь **1256/1256**:
  `resume-copy-source-unit-1.txt`, `resume-copy-source-transport-1.txt`.
- Critical **901/901**, source check успешен:
  `resume-copy-source-critical-1.txt`, `resume-copy-source-check-1.txt`.
- Первые UI **12/12**, Chromium/mobile WebKit без повторов/пропусков,
  2,4 минуты: `resume-copy-source-ui-1.txt`.
- Дополнительные UI **52/52**, оба браузера без повторов/пропусков, 5,7 минуты:
  `resume-copy-source-ui-2.txt`. 36 проверок потерянного ответа B, квоты плана C
  и изменившейся версии B, плюс 16 регрессионных. Всего **48 новых UI-сценариев
  + 16 регрессионных**, без пересечения между двумя прогонами.

Этот этап не закрывает отдельные ожидающие команды metadata, личные
направления с зависимостями, создание цели внутри другой копии, фото/архивы,
старые данные и хранение/аудит. Общая приёмка остаётся 2/12, раздел 11 — 0/10.
