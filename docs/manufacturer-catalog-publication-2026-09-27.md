# Утверждённый каталог — 27 сентября 2026

Публикация v1655 применяет 362 сохранённых подтверждения к 344 моделям.
Итог: 624 модели, две новинки (Arkel Bug и ORTLIEB Back-Roller Zip-Pocket),
37 ручных исключений. Исходные отчёты и решения в API сохранены.
Дата появления новинок задаётся в publication history; 622 исходные модели
остаются базовой загрузкой без отметки «Новинка».

Компилятор `scripts/compile-approved-manufacturer-catalog.mjs` проверяет исходные
значения каждого утверждённого поля, состав предложенной галереи и сохранённый
выбор фотографий. Незавершённые решения, конфликтующие подтверждения, пустые
галереи и отсутствующие локальные снимки останавливают подготовку. Поля из
фотографического отчёта не заменяют утверждённые характеристики целой карточки.
Сначала применяются характеристики, затем выбранные галереи. Ручная привязка
имеет отдельное происхождение `manual-catalog-review`.

Для Trunk-Bag и Vario Lite уточнение объёма переносит подтверждённую производителем
привязку размера на сохранённые снимки. В итоговых 624 карточках нет пустых
галерей; утверждённые значения и все 257 сохранённых выборов фотографий сверены
после преобразования моделей для интерфейса.

`manufacturer-catalog-review-publications.js` содержит квитанции для исключений:
номер проверки, записи и точное время решения. Комментарии пользователя сюда не
копируются. Более позднее решение той же записи снова ожидает публикации.

Новые файлы фотографий добавляются под отдельными именами. Перед добавлением
проверяются все хэши; существующие файлы не заменяются и не удаляются. После
этого приложение выпускается штатным ApplicationOnly-сценарием с проверкой
точного commit, локальными проверками, Linux-проверкой, резервной копией,
проверкой полного manifest и публичных HTTPS-файлов. Приватный экспорт решений
и материалы выпуска находятся в ignored `node_modules/.cache`.
