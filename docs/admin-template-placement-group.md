# Группа из вещей в административном шаблоне

11.09.2026, продолжение FE `a79a50a` / BE `7a2d9b5`.
Без публикации, флаги OFF; backend runtime `444808c` не менялся.

Перетаскивание вещи на другую вещь создаёт одну сохраняемую группу в
demo/shared. ID новой группы привязан к UUID действия. Место группы и порядок
двух вещей фиксируются при отпускании; сохраняются количества размещения,
все прежние ID и соседние записи. Пустой исходный карман остаётся в укладке.
Вещи могут находиться в одном родителе или в разных.

Планировщик проверяет владельцев, точный исходный arrangement, отсутствие
коллизии нового ID и фотографий. После группировки он восстанавливает исходные
количества двух вещей, которые удаление/повторная вставка иначе заменили бы
каталожными значениями. Изменённые каталожные связи и новая запись группы
входят в один план. Отказ первого зеркала возвращает прежний снимок; дальнейшие
сбои сохраняют группу для продолжения с тем же UUID.
