# Копирование в шаблон с ожидающими изменениями

11.09.2026. Продолжение `admin-template-live-copy-chain.md`.
Переход не публикуется; исходные флаги OFF.

Выбор вещи или дерева из другого подготовленного шаблона теперь допускает
целевой шаблон с надёжно сохранённой ожидающей правкой или изменением параметров.
Копия содержит полный будущий снимок цели вместе с её прежними изменениями.
Собственная база копии — ID последнего действия цели; источник имеет отдельную
проверку версии/снимка и может сам ожидать предшественника.

Перед открытием подтверждения и повторно при согласии проверяются сохранённый
план цели, его хеш, снимок редактора и отсутствие записанного решения остановить
цепочку. Для параметров используется сохранённая подтверждённая основа данных
и проверенные предшественники. Локальное чтение неактивной цели сохраняет
проверки администратора, аккаунта, маршрута и активного источника.

После подтверждения остаются прежние гарантии зеркала, журнала и указателя:
ошибка первого зеркала откатывает копию; дальнейшая нехватка места сохраняет
точный результат и ID для продолжения. Захват прежней правки в памяти снимается
только после записи дочернего плана. Цепочку можно подтвердить и продолжить
редактирование в том же окне.

Серверный контроль: **421/421 API/MySQL**, включая 32 новых сценария двух
административных видов цели, независимого порядка доставки обоих родителей,
остановки цели, более позднего изменения цели/источника и неизменности квитанции
после перезапуска. BE `729a25f` только локально; обработчик `a631516` не менялся.
Журнал `resume-pending-target-api-1.txt` в
`node_modules/.cache/causal-evidence/2026-09-08/`.

Браузерная проверка: **64 новых + 56 регрессионных сценариев** имеют успешные
прогоны Chromium и mobile WebKit без повторов и пропусков в завершающих наборах.
`resume-pending-target-ui-5.txt` — 8/8 (параметры и остановка в другой вкладке),
`ui-6` — все 56 Chromium успешны; мобильная часть остановлена после двух
ошибочных ожиданий отсутствия запросов источника. `ui-8` — 56/56 mobile WebKit,
7,5 минуты, после уточнения этих ожиданий. Это не один общий чистый прогон 120/120.

Проверены вещь/дерево, оба ожидающих родителя, потеря подтверждения, три места
отказа хранения, отмена, изменение/повреждение цели, параметры и следующая
правка без reload. Остановка через настоящее окно во второй вкладке после
открытия подтверждения копии блокирует добавление к остановленной цепочке.
Контроль прежнего поведения включает подтверждённые цели всех сочетаний
demo/shared, ожидающие источники и неподтверждённую правку без сохранённого плана.

Первые ошибки тестов: ожидание уведомления обычной правки в сценарии параметров;
затем ожидание отсутствия любых POST, хотя собственный сохранённый родитель
источника имеет право отправляться. Теперь допускается только точное тело
этого родителя с прежними ID/списком; ранний запрос копии по-прежнему запрещён.
Поведение приложения и проверки результатов не ослаблялись. `ui-3` не запустил
тесты из-за временной Windows-ошибки открытия создаваемого файла каталога;
`ui-7` остановлен до тестов. Модульные проверки: очередь **1280/1280**, critical
**901/901**, source check exit 0 (`resume-pending-target-{transport,critical,check}-1.txt`).

Файлы/архивы, ожидающие личные источники и создание цели требуют отдельных
проверок. Нативные ошибки WebKit остаются открытыми; общие критерии 2/12 и 0/10
не закрываются этим изменением.
