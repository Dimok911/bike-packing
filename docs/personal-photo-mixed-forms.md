# Смешанные фотоформы — локальный этап 2026-09-08

Обычная форма существующей вещи/сумки фиксирует поля, удаление старых фото,
новые полные файлы и окончательный порядок как одно действие. До ожидания
хранилища и SELECT-only чтения версий назначаются operation/asset/photo IDs
и копируется выбор пользователя. Ответ с другими полями владельца или версией
не заменяет исходный выбор. После ожиданий правки открытой формы не меняют
уже зафиксированное действие.

План последователен: удаления с отдельными числовыми версиями фото, прикрепления
новых файлов и одна заключительная перестановка. Каждый промежуточный массив
ID проверяется сервером и клиентским валидатором квитанции. Полный состав
действия ограничен 50 изменениями. Файловое хранилище содержит только новые
файлы, но его hash охватывает полное действие и итоговый снимок, включая удаления
и порядок. Неполный набор файлов не подтверждает форму.

Общий photo-only batch не получил нового разрешения на перестановку после
attach. Исключение передаётся кодом только валидатору формы; параметр HTTP
его не включает. Смешанная запись и отправка требуют уже существующий gate
`PERSONAL_PHOTO_EDIT_FORM_ENABLED`, который остаётся выключенным.
При выключенном gate прежний UI не включает смешанный путь.
