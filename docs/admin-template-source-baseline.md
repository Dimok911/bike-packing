# Исходный снимок для команд параметров шаблона

Продолжение 11.09.2026. Локальный переход, без публикации; флаги OFF.

После открытия demo/shared сохраняется точный серверный снимок вместе с
отдельным экспортом редактора. Они могут различаться: редактор нормализует ID,
названия и описание. Команда изменения названия/языка сохраняет данные сервера,
поэтому следующая копия вещи, дерева или шаблона использует исходные данные,
а зависимостью назначает UUID команды параметров.

Снимок привязан к аккаунту, среде, шаблону, локальному редактору и ревизии.
Он неизменяем, проверяется по хешу и не создаёт серверное действие. При
переполнении хранилища шаблон по-прежнему открывается; копия без доказуемого
источника остаётся в форме. Повреждённый снимок не подменяется текущим экспортом.
Захват проверяет смену контекста до и после ожидания. Фоновое восстановление
черновиков использует тот же путь.

Если перед параметрами уже подтверждена местная правка или целая копия,
предшественник находится по проверенной сохранённой квитанции этой ревизии.
Совпадения только номера недостаточно: требуются точные действие, namespace,
шаблон и единственный сохранённый план. Цикл, отмена или посторонняя правка
вещей/сумок/описания блокируют подготовку. Несколько команд параметров могут
последовательно восстанавливать источник через такую цепочку.

Это не мигрирует уже открытые редакторы без снимка и не очищает их журналы.
Если нет ни точного снимка, ни проверенного местного предшественника,
ожидающий источник требует подтверждения исходной команды. Хранение и очистка
снимков входят в ещё открытый общий пункт retention/audit. Отдельные команды
публикации/архива, порядок из другого пакета, личные зависимости, создание цели
внутри копирования и файлы остаются следующим объёмом. Крупные критерии
перехода **2/12**, административные **0/10**; нативные сбои WebKit не исправлены.
