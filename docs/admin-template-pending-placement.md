# Размещения после ожидающей административной правки

11.09.2026. Продолжение `admin-template-pending-target.md` и
`admin-template-live-copy-chain.md`. Публикации нет, исходные флаги OFF.

Проверяются настоящие обработчики перемещения вещи/вложенной сумки и
группировки двух вещей в одном либо разных родителях. Предыдущая правка данных
или названия остаётся отдельным сохранённым действием. Новый план ссылается
на её UUID; до подтверждения предшественника он не отправляется. После reload
используется тот же план, сохраняются прежние ID, количества и порядок;
для группы создаётся ровно один новый ID. Следующая правка использует уже
подтверждённую версию результата.

Используется общий адаптер ожидающей цели, добавленный ранее. Код приложения
и обработчик API здесь пока не менялись. Эта проверка не закрывает все
административные действия, фото/архивы или общую приёмку WebKit.

Новая UI-матрица включает оба namespace и браузера: данные/параметры,
потерю ответа предшественника, отказ записи плана/зеркала и остановку цепочки.
При отказе зеркала прежний снимок возвращается целиком; при отказе плана
новая группа остаётся для продолжения с тем же ID. Остановленная цепочка не
принимает новое размещение.
