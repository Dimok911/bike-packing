# Целый ожидающий шаблон → новый административный черновик

Локальное продолжение 11.09.2026. Публикаций нет, исходные флаги OFF;
сервер `a631516` не менялся и остаётся только локальным.

Форма создания копии целого demo/shared принимает источник с уже
сохранённым ожидающим планом данных. Цепочки сохранения/публикации также проверены
следующим срезом: `admin-template-pending-visibility-source.md`.
Через проверенное хранилище плана читаются
его точное тело, metadata и UUID. Снимок открытого редактора обязан полностью
совпасть с этим шагом. В новый `template.copy` записывается
`source.base: { operationId }`, хеш источника и прежний сохранённый план
выделения всех новых ID. Серверная подготовка старой версии не подставляется.

Можно выбрать и неактивный ожидающий черновик: чтение плана не переключает
пользовательский контекст и не отправляет исходное действие. Пока оно не
подтверждено, сервер не создаёт целевой шаблон. После подтверждения источника
продолжается исходная копия. Сохраняются язык, справочники, порядок, вложенность,
количества и отдельные записи каталога. Новый шаблон остаётся приватным.

Форма проверяет выбранный способ создания, источник, название и открытое окно
до сохранения новой копии, в том числе после асинхронных чтений/вычисления хеша.
Закрытие формы или изменение выбора останавливает подготовку. Проверка действует
и для ранее подтверждённого источника. Поздняя правка, которой нет в сохранённом
шаге источника, требует сверки вместо копирования.
