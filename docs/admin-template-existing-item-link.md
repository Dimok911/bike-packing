Кнопка добавления существующей отдельной вещи в сумку или вложенный карман
подготовленного demo/shared теперь сохраняет полный план до отправки.
Используется тот же ID вещи; новое размещение получает каталожное количество,
без отметки упаковки. Прежний состав цели сохраняется. Повторный запрос и
reload продолжают прежний UUID. При отказе первого зеркала форма остаётся
открытой, исходные данные не меняются. При отказе журнала или ссылки редактора
сохранённый план восстанавливается из зеркала.

Это исправляет воспроизведённую потерю действия после отказа записи журнала:
старый путь успевал изменить местное состояние, но после reload не мог
подтвердить добавление. Первые ошибки и traces сохранены, проверки не ослаблены.
Пока разрешена отдельная вещь вне укладки, не входящая в detached-дерево
каталога; чужие, неподготовленные, недоступные и содержащие фото записи
останавливаются до изменения состояния. Замена вещи — отдельный открытый путь.
