Форма вещи предлагает сумку или вложенный карман другого заранее открытого,
подготовленного demo/shared. Копия получает независимый ID и принадлежность
цели. Исходная вещь и исходный шаблон остаются целыми. Количество соответствует
прежней форме копирования: для размещённой вещи одна штука, для вещи вне
укладки — каталожное количество. У копии нет отметки упаковки. Прежний порядок,
содержимое и количества цели не меняются; новая вещь добавляется в конец сумки.

Подготовка вещей и деревьев использует общий адаптер сохранения размещённой
копии. Он сохраняет обе версии, исходный серверный снимок, итог цели и UUID в
плане v4 до переключения редактора. Проверка source-checked save и отдельной
возможности сервера не менялась. Отдельный чистый планировщик вещи проверяет
принадлежность, доступность и отсутствие файлов; исправление повреждённого
старого размещения не включается в копирование неявно.
