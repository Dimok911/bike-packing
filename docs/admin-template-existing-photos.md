# Сохранение существующих фото административного шаблона

11.09.2026. Клиентский срез поверх локального BE `a17d2f5`. Публикации нет,
флаги исходников OFF. Полный административный файловый пакет ещё не завершён.

## Результат

Обычная правка полей demo/shared шаблона может сохраняться через
`template.save`, сохраняя существующие фотографии и их владельцев точно.
Сервер проверяет исходный и новый набор ссылок, владельцев и строки фото
под блокировкой в транзакции. Несоответствие откатывает запись; новая
загрузка, удаление/порядок и копирование файлов требуют следующего адаптера.

Редактор хранит отдельный `adminCausalSource.photoView`: точные исходные
ссылки и их нормализованное представление с явной картой local→server.
`id`/`photoId`, старые имена URL, отсутствующий status и дополнительные поля
не теряются. Перед экспортом проверяется полное живое представление;
после экспорта восстанавливаются только неизменённые исходные ссылки.
Серверные ID владельцев фото сохраняются явно. Эта локальная карта не
заменяет серверную проверку и не передаётся в бизнес-payload.

Перезагрузка и потеря ответа используют прежний план/ID. Выбор местного
варианта сохраняет уже зафиксированную карту; выбор серверного варианта
сохраняет подготовленную проекцию. Неверный источник demo проверяется в
отдельном состоянии до добавления записей в общий каталог или local mirror.

## Проверка

оба типа шаблонов; обычное сохранение и потерянный ответ; перезагрузка и
следующая правка; выбор местного/серверного варианта после остановки;
неверный источник фото без оставленного черновика и исправленное открытие.
Точный набор исходных ссылок проверяется при каждом принимаемом POST.
Отдельно выполняются прежние сценарии серверного выбора без фотографий.

binding, неоднозначные карты, потеря полей старого формата, квота/reload
при выборе местного варианта. Серверный набор включает сохранение строк

## Остаток

Загрузка/удаление/порядок фото, межшаблонная файловая копия, публикация
с файлами и ZIP-восстановление не закрыты этим срезом. Проверяется сохранность
ссылок и строк БД; наличие и хеши физических файлов — работа файлового пакета.
Автоматического преобразования старого местного черновика с фото без baseline
нет; его восстановление остаётся в блоке старых данных и требует сверки.
Нативный WebKit и проверка на настоящем iPhone/Safari остаются открытыми.
