# Копия из ожидающей цепочки сохранения и публикации

Локальное продолжение 11.09.2026. Публикация сайта и рабочих данных не
выполнялась, исходные флаги OFF. Проверки используют управляемый API браузерных
тестов и отдельную тестовую MySQL.

Источник копии использует снимок шага данных и UUID последнего шага выбранного
плана. Для «сохранить → опубликовать» это UUID публикации, для «снять публикацию
→ сохранить» — UUID записи данных. Выбор не сокращает цепочку до её первого
успешного шага. Полная грамматика плана проверяется перед извлечением снимка;
перестановка операций, разрыв зависимости, отмена плана и поздняя правка
редактора останавливают копирование.

Применяется прежний серверный `source.base: { operationId }` и проверка хеша
точного источника. Серверный код после `a631516` не менялся: расширены API-тесты.
Неизвестный последний шаг оставляет копию в ожидании; отменённый последний
шаг даёт окончательный отказ без создания/изменения цели. Ранее принятые
квитанции и выбранные новые ID сохраняются при повторе.
